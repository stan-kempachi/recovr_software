📄 Cahier des Charges – RecovR
Outil SaaS de contrôle du processus de facturation et suivi des statuts (Chorus Pro & Ariba)
________________________________________
1. Présentation du projet
Nom du projet : RecovR
 Type : Application web SaaS
 Objectif :
●	Automatiser la vérification du respect du processus de facturation client.

●	Centraliser le suivi des statuts de factures sur Chorus Pro, Ariba et autres plateformes.

●	Réduire les délais de paiement et améliorer le recouvrement.

Public cible :
●	Grandes entreprises et ETI avec flux de factures important.

●	PME sous-traitantes avec contraintes de facturation spécifiques.

●	Cabinets de gestion et recouvrement.

________________________________________
2. Fonctionnalités principales (MVP – M0 à M3)
2.1 Authentification & gestion utilisateurs
●	Connexion sécurisée (OAuth2 / SSO en option).

●	Gestion multi-comptes (Admin / Utilisateur / Lecture seule).

●	Stockage sécurisé des identifiants API Chorus Pro & Ariba.

2.2 Connexion aux plateformes
●	Intégration API Chorus Pro (lecture statuts, envoi factures).

●	Intégration API Ariba (lecture statuts, tracking PO).

2.3 Contrôle de conformité des factures
●	Vérification des documents requis (PO, BL, PV, CRA).

●	Alertes en cas de document manquant avant dépôt.

●	Validation manuelle ou automatique.

2.4 Suivi & alertes
●	Tableau de bord avec statut des factures (Soumise, Acceptée, En litige, Payée).

●	Notifications par email & dans l’app pour retards ou anomalies.

2.5 Reporting basique
●	Export Excel/CSV des statuts et délais de paiement.

3. Évolutions prévues (M4 à M12)
Mois	Évolution

M12	Tableau de bord mobile (PWA).
________________________________________
4. Architecture technique
●	Front-end : React.js + TailwindCSS

●	Back-end : Node.js / Express ou Python (FastAPI)

●	Base de données : PostgreSQL (hébergée sur AWS RDS)

●	Intégrations API : Chorus Pro, Ariba (et futures plateformes)

●	Hébergement : AWS (EC2 + S3)

●	Sécurité : chiffrement SSL/TLS, stockage mots de passe avec bcrypt, logs chiffrés.

________________________________________
5. Design & UX
●	Interface épurée, dashboard avec codes couleurs (vert=OK, orange=En attente, rouge=Blocage).

●	Navigation simple (max 3 clics pour accéder à une info).

●	Responsive (desktop, tablette, mobile).
